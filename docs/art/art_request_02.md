# Strange Ranger: Art Request 02

From the lab, 15 November 2026. These are the pictures phase 2a still shows as plain stand-ins, plus two left over from last time: 27 pictures on four sheets. Make the sheets, send them back with these file names, and the lab will clean them, check them and put them in the game.

## How to make each sheet

Same rules as Art Request 01. Your first two batches came through well.

- **Use the forest palette** (strange_ranger_palette.png). The tool snaps every colour to it.
- **One picture per cell, in the grid shown.** Leave clear space between items.
- **Nothing crosses a cell edge.**
- **Each item is one connected piece.** Small parts must touch the main shape.
- **Use a transparent background**, or one flat plain colour. No glows, cast shadows or gradients on the background.
- **Keep the same look as your other sheets:**
  - cozy 16-bit top-down pixel art;
  - dark brown outlines;
  - warm earthy colours;
  - seen from slightly above, like Stardew Valley.
- **Size:** any square sheet works; about 1254 × 1254 is fine. The tool crops each item to its outline and shrinks it to the game size, keeping its shape. Draw each item at the proportions given.
- **PNG files**, named exactly as given.
